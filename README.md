# Лабораторная работа 11
## Было создано приложение, которое:
- Использует Retrofit и Gson для выполнения HTTP GET-запроса к публичному API JSONPlaceholder (/posts).
- Получает список постов (заголовок, текст, ID пользователя) в формате JSON и преобразует их в объекты Kotlin.
- Отображает данные в Jetpack Compose:
  - Показывает индикатор загрузки во время запроса.
  - При успехе выводит список постов в виде карточек (LazyColumn).
  - При ошибке показывает сообщение об ошибке и кнопку повтора.
- Сетевой вызов выполняется асинхронно в фоновом потоке (корутины, Dispatchers.IO), а UI обновляется в главном потоке.
